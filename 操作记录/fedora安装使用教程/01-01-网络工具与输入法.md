# 网络工具与输入法（Clash + Rime）

> 这篇放在 [[01-Fedora安装与初始化]] 之后、 [[02-Fedora-Docker安装与使用]] 之前。
> 原因：clash 是后面所有下载的前置，rime 是日常输入工具，越早装越好。

## 1. 网络代理：Mihomo（原 Clash Meta）

**为什么不直接装 Clash**：原版 Clash Premium 已被作者删库，目前社区主流是 **Mihomo（MetaCubeX）**——开源、活跃、兼容 Clash 配置。

### 1.1 安装 Mihomo 二进制（推荐，systemd 服务化）

```bash
# 走临时代理（如果本机已经有 macOS 的代理网关，先在另一台下载好再传过来；
# 或者临时用其它出口拉）
export https_proxy=http://127.0.0.1:7890

# 下载最新版（amd64）
MIHOMO_VER=$(curl -sL https://api.github.com/repos/MetaCubeX/mihomo/releases/latest \
  | grep -oE '"tag_name": *"v[^"]+"' | sed 's/.*v//;s/"//')
curl -L -o /tmp/mihomo.gz \
  "https://github.com/MetaCubeX/mihomo/releases/download/v${MIHOMO_VER}/mihomo-linux-amd64-v${MIHOMO_VER}.gz"

gunzip /tmp/mihomo.gz
sudo install -m 755 /tmp/mihomo /usr/local/bin/mihomo
mihomo -v
```

### 1.2 准备配置目录

```bash
sudo mkdir -p /etc/mihomo
sudo tee /etc/mihomo/config.yaml <<'EOF'
# 占位：用你自己的订阅链接替换 url
mixed-port: 7890
allow-lan: true
bind-address: "*"
mode: rule
log-level: info
external-controller: 127.0.0.1:9090
secret: ""    # 控制台密码

# 订阅
proxy-providers:
  provider1:
    type: http
    url: "https://your-sub-link.example.com/sub?u=xxx"   # ← 改成你的机场订阅
    interval: 3600
    health-check: { enable: true, url: "http://www.gstatic.com/generate_204", interval: 300 }
    override:
      additional-prefix-str: ""   # 部分机场需要 prefix

# 规则集
rule-providers:
  direct:
    type: http
    url: "https://raw.githubusercontent.com/Loyalsoldier/clash-rules/release/direct.txt"
    behavior: classical
  proxy:
    type: http
    url: "https://raw.githubusercontent.com/Loyalsoldier/clash-rules/release/proxy.txt"
    behavior: classical
  private:
    type: http
    url: "https://raw.githubusercontent.com/Loyalsoldier/clash-rules/release/private.txt"
    behavior: classical
  gfw:
    type: http
    url: "https://raw.githubusercontent.com/Loyalsoldier/clash-rules/release/gfw.txt"
    behavior: classical

rules:
  - RULE-SET,private,DIRECT
  - RULE-SET,gfw,provider1
  - RULE-SET,proxy,provider1
  - RULE-SET,direct,DIRECT
  - GEOIP,CN,DIRECT
  - MATCH,provider1
EOF

sudo chmod 644 /etc/mihomo/config.yaml
```

### 1.3 systemd 服务

```bash
sudo tee /etc/systemd/system/mihomo.service <<'EOF'
[Unit]
Description=Mihomo (Clash Meta) Daemon
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=nobody
ExecStart=/usr/local/bin/mihomo -d /etc/mihomo
Restart=on-failure
RestartSec=5s
LimitNOFILE=65536
AmbientCapabilities=CAP_NET_ADMIN CAP_NET_BIND_SERVICE CAP_SYS_PTRACE CAP_DAC_OVERRIDE
CapabilityBoundingSet=CAP_NET_ADMIN CAP_NET_BIND_SERVICE CAP_SYS_PTRACE CAP_DAC_OVERRIDE

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now mihomo
sudo systemctl status mihomo
```

### 1.4 验证 + 切代理

```bash
# 验证端口在听
ss -tlnp | grep 7890

# 测试能不能访问被墙的站
curl -x socks5h://127.0.0.1:7890 https://www.google.com -I

# 全局走代理（写到 ~/.zshrc）
echo 'export https_proxy=http://127.0.0.1:7890'  >> ~/.zshrc
echo 'export http_proxy=http://127.0.0.1:7890'   >> ~/.zshrc
echo 'export all_proxy=socks5://127.0.0.1:7890'  >> ~/.zshrc
exec zsh
```

### 1.5 让 dnf / docker / git / npm 都走代理

```bash
# dnf 已经在 [[01-Fedora安装与初始化]] 里写了，重复一下引用
sudo tee /etc/dnf/dnf.conf.d/00-proxy.conf <<'EOF' 2>/dev/null || true
[main]
proxy=https://127.0.0.1:7890
EOF

# git
git config --global http.proxy  http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890

# npm（如果你已经装好 node）
npm config set proxy http://127.0.0.1:7890
npm config set https-proxy http://127.0.0.1:7890

# docker（需要时）— 直接改 daemon.json 或留给 [[02-Fedora-Docker安装与使用]]
```

### 1.6 GUI 控制台（可选）

不想敲命令的话，装一个桌面客户端：

```bash
# Clash Verge Rev（Rust 写的，推荐）
# AppImage
wget -O /tmp/cvr.AppImage \
  https://github.com/clash-verge-rev/clash-verge-rev/releases/download/v2.2.3/Clash.Verge.Rev_2.2.3_amd64.AppImage
chmod +x /tmp/cvr.AppImage
sudo mv /tmp/cvr.AppImage /usr/local/bin/clash-verge-rev

# 或者 mihomo-party（Electron，也是 MetaCubeX 官方 GUI）
# https://github.com/xjasonlyu/mihomo-party/releases
```

GUI 客户端连接 `127.0.0.1:9090` 控制台，可以切节点 / 看流量 / 改规则。

### 1.7 透明代理 / TUN 模式（高级）

如果你想让所有流量（包括未配置代理的应用）都走代理，开 TUN 模式：

```bash
# /etc/mihomo/config.yaml 加：
tun:
  enable: true
  stack: system
  dns-hijack:
      - any:53
      - tcp:53
  auto-route: true
  auto-detect-interface: true
```

需要给 mihomo 二进制加 cap_net_admin 权限（systemd 单元里已加）。

> 不建议在 Wayland 上用 TUN，可能会和 GNOME 的某些组件冲突，先用 mixed-port 模式。

## 2. Rime 输入法（fcitx5-rime）

Fedora Wayland 下推荐 **fcitx5 + fcitx5-rime**，比 ibus-rime 体验好。Mac 端的配置见 `操作记录/rime安装和配置.md`，这里讲 Linux 侧如何把同一份配置同步过来。

### 2.1 安装

```bash
sudo dnf install -y \
  fcitx5 fcitx5-chinese-addons \
  fcitx5-rime fcitx5-configtool \
  fcitx5-gtk fcitx5-qt

# Wayland 下还需要 portal 选 gtk
sudo dnf install -y xdg-desktop-portal-gtk xdg-desktop-portal-gnome
```

### 2.2 环境变量（Wayland）

```bash
# ~/.zshrc
echo 'export GTK_IM_MODULE=fcitx'   >> ~/.zshrc
echo 'export QT_IM_MODULE=fcitx'    >> ~/.zshrc
echo 'export XMODIFIERS=@im=fcitx'  >> ~/.zshrc
echo 'export INPUT_METHOD=fcitx'    >> ~/.zshrc
echo 'export SDL_IM_MODULE=fcitx'   >> ~/.zshrc
exec zsh

# 启动 fcitx5（也可以用 systemd 用户实例）
fcitx5 -d   # daemonize
```

### 2.3 启用 rime 输入法

```bash
# 配置 fcitx5 默认输入法和顺序
fcitx5-configtool
# 在 "输入法" 标签页：
#   - "添加" → 搜索 "rime" → 选中
#   - 把 rime 放到第一位
#   - "全局选项" → "共享输入状态" 勾选
```

### 2.4 rime 配置目录

```bash
# fcitx5-rime 默认读取：
ls ~/.local/share/fcitx5/rime/        # 用户配置
ls /usr/share/rime-data/              # 系统数据
```

### 2.5 与 Mac 同步（dotfiles 共享）

参考 macOS 上 `操作记录/rime安装和配置.md` 的 dotfiles 模式：

```bash
# 假设你的 dotfiles 仓库：~/code/dotfiles
# 把 rime 配置放在 ~/code/dotfiles/rime

# 在 Fedora 上链过去
rm -rf ~/.local/share/fcitx5/rime
ln -s ~/code/dotfiles/rime ~/.local/share/fcitx5/rime

# 触发重新部署（导入新词库会要求）
fcitx5 -r   # 重启 fcitx5
# 然后在 rime 输入状态下按 F4 → 「重新部署」
```

### 2.6 同步用户数据（Mac ↔ Fedora）

rime 的用户数据（词频、个性化）存在：

```text
~/Library/Rime/                # macOS
~/.local/share/fcitx5/rime/    # Fedora（含 sync/ 目录）
```

推荐用 rime 自带的同步机制（用云盘或 git）：

```bash
# 在配置里加：rime.yaml
sync:
  sync_dir: "Sync/rime-user-data"   # 对应 iCloud / Dropbox / OneDrive 路径
  capitalization: true

# 或者简单粗暴：cron + rsync 到同一个目录
```

### 2.7 几个常见配置

```yaml
# default.yaml（rime 配置）
schema_list:
  - schema: luna-pinyin
  - schema: double-pinyin       # 如果用双拼
  - schema: cangjie5            # 如果用仓颉

key_bindings:
  - { when: composing, accept: Tab, send: Page_Down }      # Tab 翻页
  - { when: composing, accept: Control+j, send: Down }     # Ctrl+J 下翻
  - { when: composing, accept: Control+k, send: Up }
  - { when: composing, accept: Shift+space, send: Escape } # Shift+Space 中英切换
  - { when: has_menu, accept: Escape, send: Escape }
```

具体配置参考 `操作记录/rime安装和配置.md`（已有完整流程）。

## 3. 我的判断

- **Clash 不用原版**：原版已经被作者下架，下载的二进制通常是别人 fork 改的（有后门风险）。Mihomo 是 MetaCubeX 的官方 fork，社区版本最新，最稳。
- **systemd 服务化 vs GUI**：长期开机跑用 systemd（开机自启，崩溃自愈），临时调试用 GUI。建议**生产用服务、调试用 GUI**。
- **TUN 模式谨慎开**：透明代理虽爽，但和 firewalld / docker 网络可能冲突，新手先别开。
- **rime 用 fcitx5 比 ibus 强**：在 Wayland 下尤其明显，多进程支持、emoji 候选、皮肤都更现代。
